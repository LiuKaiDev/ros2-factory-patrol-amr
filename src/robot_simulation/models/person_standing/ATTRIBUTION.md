# Standing Person Asset

Source: `osrf/gazebo_models/person_standing` at commit
`8163eb4b5e7e21985c6591d1c0bfb56468c0093f`.

Original author: Marina Kollmitz. The model was created with MakeHuman.

License: Creative Commons Attribution 3.0 Unported. See `LICENSE`.

Repository changes: collision and inertial elements were removed to make this
a static visual-only detector target, and all referenced textures were
downscaled to at most 512 x 512 pixels. Unsupported FCOLLADA bump-map effects
were removed; the mesh geometry and diffuse materials are unchanged.
